# Запуск приложения на сервере

> Статус: **рабочая процедура** · id: `P002` · версия схемы: 1

Скопировать артефакт, распаковать, перезапустить службу, проверить health-эндпоинт

## Параметры

| Параметр | Тип | Пример | Пояснение |
|---|---|---|---|
| `HOST` | host (переменная) | `server1` | целевой сервер (user@host в ssh/scp) |
| `PORT` | port (переменная) | `8080` | порт health-эндпоинта |
| `APP_DIR` | path (переменная) | `/opt/app` | директория развёртывания |

## Предпосылки

- Нет (процедура автономна)

## Шаги

### 1. Скопировать артефакт на сервер

```
scp build.tar.gz deploy@{{HOST}}:{{APP_DIR}}/
```

_Проверка: exit_code → 0_

### 2. Распаковать артефакт

```
ssh deploy@{{HOST}} "cd {{APP_DIR}} && tar xzf build.tar.gz"
```

### 3. Перезапустить службу

```
ssh deploy@{{HOST}} "systemctl restart app"
```

### 4. Проверить health-эндпоинт

```
curl -sf http://{{HOST}}:{{PORT}}/health
```

_Проверка: http_status → 200_


## Критерии успеха

- [http_status] 200
- [exit_code] 0

## Если что-то пошло не так

- Проверь критерии успеха выше: какой именно шаг не прошёл проверку?
- Сверь параметры (хост, порты, пути) с таблицей в начале инструкции.
- Лимиты: таймаут шага — 600 с, максимум шагов — 20.
- Найди похожие инструкции в этой же папке и раздел «НЕРАБОЧЕЕ РЕШЕНИЕ»: возможно, процедура уже модифицировалась.
