# Проверка календаря на ближайший час

> Статус: **рабочая процедура** · id: `P003` · версия схемы: 1

Открыть Google Calendar (Playwright MCP) и определить, есть ли встреча в ближайший час. Переменных нет; критерий — ответ интерна «встреча есть/нет».

## Предпосылки

- Нет (процедура автономна)

## Шаги

### 1. Открыть Google Calendar

_Исполняет агент (инструменты браузера/MCP, с подтверждением):_

> playwright_browser_navigate на https://calendar.google.com/calendar/r, дождись загрузки страницы (playwright_browser_snapshot). Если открылась страница входа в Google — сообщи пользователю, что нужно войти (пароль вводит только пользователь), и дождись входа.

_🔒 подтверждение пользователя_

### 2. Определить наличие встреч в ближайший час

_Исполняет агент (инструменты браузера/MCP, с подтверждением):_

> playwright_browser_snapshot текущего вида календаря. Определи текущее системное время (не время со страницы). Проверь, есть ли события в интервале [сейчас; +60 минут]: заголовки/блоки событий на шкале времени. Итоговый ответ пользователю строго одного из двух видов: «ВСТРЕЧА ЕСТЬ: <название>» либо «ВСТРЕЧ НЕТ».
